# MultiRoblox

**Open-source project for running multiple Roblox game windows.**

MultiRoblox is designed to help users open multiple Roblox instances through a web browser, making it easier to play with different accounts simultaneously.

## ✨ Features

- 🪟 Open multiple Roblox game windows.
- 🌐 Launch Roblox experiences through a web browser.
- 👥 Use different Roblox accounts in separate sessions.
- 📖 Open-source project released under the MIT License.

## 🚀 How to Use

1. Open **Google Chrome** or another supported web browser.
2. Visit the official [Roblox website](https://www.roblox.com/).
3. Sign in to your Roblox account.
4. Join any experience directly through the browser.
5. Repeat the process to open additional Roblox windows.
6. Sign in with a **different Roblox account** for each session.

**Important notes:**

- The intended workflow uses the Roblox website in a browser, rather than launching games exclusively through desktop shortcuts.
- Each session should use a different Roblox account. You cannot use the same account to join the same experience in multiple independent sessions in the way described here.
- The number of instances you can run depends on your system resources and Roblox's current behavior and restrictions.
- Some browser or Roblox configurations may require additional setup.
