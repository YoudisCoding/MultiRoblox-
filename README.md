# MultiRoblox

**An open-source C++ project for Windows 11 designed to help users open multiple Roblox game sessions.**

MultiRoblox is intended for people who want to launch Roblox experiences from a web browser while using different Roblox accounts.

## ✨ Features

- 🌐 Browser-based Roblox workflow.
- 👥 Intended for use with separate Roblox accounts and sessions.
- 💻 Written in C++ for Windows.
- 📖 Open-source project under the MIT License.

## 🖥️ Requirements

- Windows 11
- Microsoft Visual Studio with the **Desktop development with C++** workload
- Google Chrome or another supported browser

## 🛠️ Build from Source

### 1. Install Visual Studio

Install [Visual Studio](https://visualstudio.microsoft.com/vs/) and select **Desktop development with C++** in the Visual Studio Installer. This installs the MSVC compiler and the Windows C++ build tools.

### 2. Download the source code

Clone this repository:

```bash
git clone https://github.com/YoudisCoding/MultiRoblox-.git
cd MultiRoblox-
```

Or, on GitHub, select **Code → Download ZIP** and extract the archive.

### 3. Open the source in Visual Studio

- If the repository includes a Visual Studio solution (`.sln`) or C++ project (`.vcxproj`), open it in Visual Studio.
- If it contains only C++ source files, create or configure a C++ project and add the required source files. The exact setup depends on the files and dependencies in the repository.

### 4. Compile

1. Select the **Release** configuration.
2. Select **x64** if it is supported by the project.
3. Choose **Build → Build Solution** (or **Build → Build** for the selected project).
4. If compilation fails, check the **Output** and **Error List** windows for details.

After a successful build, Visual Studio places the output in the configured output directory. Common locations include `x64/Release/` and `Release/`; the exact path depends on the project settings.

**Important:** These are general Visual Studio C++ build steps. The repository must contain the required source files and project configuration for the build to succeed.

Official guide: [Build C++ projects in Visual Studio](https://learn.microsoft.com/en-us/cpp/build/creating-and-managing-visual-cpp-projects?view=msvc-170).

## 🚀 How to Use

1. Open [Roblox](https://www.roblox.com/) in your browser.
2. Sign in and join an experience from the Roblox website.
3. Use separate browser profiles or sessions to sign in with different Roblox accounts.
4. Join the experience in each session, if supported by your browser and Roblox setup.

The number of sessions you can run depends on your PC's resources and Roblox's current behavior and restrictions. Launching through a browser may behave differently from using desktop shortcuts.
